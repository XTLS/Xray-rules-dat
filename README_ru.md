# Xray-rules-dat

[English](./README.md) | [简体中文](./README_zh_Hans.md) | Русский | [فارسی](./README_fa.md)

---

Данные GeoIP и GeoSite для [Xray](https://github.com/XTLS/Xray-core).

GeoIP основан на [IPinfo Lite](https://ipinfo.io/lite) и дополнен IP-данными для региональных задач маршрутизации и популярных сервисов. Поддерживаются IPv4 и IPv6.

GeoSite пока использует исходные данные [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community) без изменений.

Сборка выполняется ежедневно в 18:00 UTC (02:00 следующего дня в Китае, 21:00 в Москве и 21:30 в Иране).

### Различия между облегчённой и полной версиями GeoIP

| Категория | Название или охват | Полная версия | Облегчённая версия |
| --------- | ------------------ | ------------- | ------------------ |
| Исходные категории стран и территорий | Исходные данные IPinfo для всех стран и территорий | Включены | Не включены |
| Anycast-адреса | `anycast` | Включены | Не включены |
| Региональные наборы | `in-cn`, `in-ru`, `in-ir` | Включены | Включены |
| Списки блокировок | `blacklist-ru`, `blacklist-ir` | Включены | Включены |
| Общие категории | `private`, `cloudflare`, `cloudfront`, `facebook`, `fastly`, `google`, `netflix`, `telegram`, `twitter`, `tor` | Включены | Включены |
| Псевдонимы для совместимости | `cn` → `in-cn`, `ru` → `in-ru`, `ir` → `in-ir` | Не предоставляются | Включены |

Принципы организации категорий и источники данных описаны в [документации GeoIP](https://github.com/XTLS/Xray-rules-dat/blob/geoip/README_zh-Hans.md).

### Файлы отдельных категорий

Если нужны только отдельные категории, можно скачать соответствующие файлы без загрузки большого `geoip-full.dat`.

Например, можно продолжать использовать облегчённую версию как `geoip.dat`: существующая категория `in-cn` по-прежнему доступна через `geoip:in-cn`. Дополнительно скачайте [us.dat](https://raw.githubusercontent.com/XTLS/Xray-rules-dat/release/geoip/dat/us.dat) в тот же каталог, чтобы использовать категорию `us` через `ext:us.dat:us`.

DAT-файлы отдельных категорий находятся в [каталоге `geoip/dat/`](https://github.com/XTLS/Xray-rules-dat/tree/release/geoip/dat) ветки `release`.

## Инструкции по загрузке

### GitHub Releases

В GitHub Releases доступны только базы DAT, каждая в виде отдельного файла. Для ручной загрузки откройте [последний выпуск](https://github.com/XTLS/Xray-rules-dat/releases/latest). Предыдущие версии доступны в [GitHub Releases](https://github.com/XTLS/Xray-rules-dat/releases).

Программы автоматического обновления могут загружать последнюю версию по следующему постоянному адресу. Замените `<filename>` нужным именем файла:

```text
https://github.com/XTLS/Xray-rules-dat/releases/latest/download/<filename>
```

### Ветка `release`

Последние версии всех файлов публикуются в [ветке `release`](https://github.com/XTLS/Xray-rules-dat/tree/release). Если нужна определённая категория, соответствующий файл можно скачать прямо из этой ветки.

Замените `<path>` путём к файлу внутри ветки, например `geoip/dat/us.dat`:

- GitHub Raw: `https://raw.githubusercontent.com/XTLS/Xray-rules-dat/release/<path>`
- Зеркало jsDelivr (по умолчанию): `https://cdn.jsdelivr.net/gh/XTLS/Xray-rules-dat@release/<path>`
- Зеркало jsDelivr (Fastly): `https://fastly.jsdelivr.net/gh/XTLS/Xray-rules-dat@release/<path>`

У зеркал jsDelivr есть [ограничение размера отдельного файла](https://github.com/jsdelivr/jsdelivr#restrictions), поэтому даже файлы отдельных категорий могут оказаться слишком большими для загрузки. Рекомендуется использовать GitHub Releases или GitHub Raw, а зеркала — при недоступности GitHub.

Рядом с каждым файлом данных находится соответствующий файл контрольной суммы `.sha256sum`.

## Использование в Xray

В дистрибутив Xray входит облегчённая версия GeoIP под именем `geoip.dat`. Её региональные наборы и общие категории можно использовать напрямую.

В следующем примере сохраняется облегчённая версия `geoip.dat`, а в тот же каталог дополнительно загружается [us.dat](https://raw.githubusercontent.com/XTLS/Xray-rules-dat/release/geoip/dat/us.dat).

Добавьте следующий фрагмент в конфигурацию Xray, чтобы ежедневно в 04:00 по местному времени среды выполнения автоматически обновлять оба файла и перезагружать их без перезапуска. Частные адреса и категория `in-cn` используют существующее исходящее подключение `direct`, а категория `us` — существующее исходящее подключение `wireguard`:

```json
{
  "geodata": {
    "cron": "0 4 * * *",
    "assets": [
      {
        "url": "https://github.com/XTLS/Xray-rules-dat/releases/latest/download/geoip-lite.dat",
        "file": "geoip.dat"
      },
      {
        "url": "https://raw.githubusercontent.com/XTLS/Xray-rules-dat/release/geoip/dat/us.dat",
        "file": "us.dat"
      }
    ]
  },
  "routing": {
    "rules": [
      {
        "ip": ["geoip:private", "geoip:in-cn"],
        "outboundTag": "direct"
      },
      {
        "ip": ["ext:us.dat:us"],
        "outboundTag": "wireguard"
      }
    ]
  }
}
```

Обновляемые файлы должны уже существовать. Дополнительные параметры приведены в [документации по настройке Geodata](https://xtls.github.io/config/geodata.html).

При необходимости замените названия категорий в примере. Порядок правил и сопоставление IP-адресов описаны в [документации Xray по маршрутизации](https://xtls.github.io/en/config/routing.html).

Существующая категория `in-cn` по-прежнему используется через `geoip:in-cn`, а дополнительно загруженная категория `us` — через `ext:us.dat:us`. Для других категорий замените `us` в имени файла и названии категории.

Категория, указанная после последнего двоеточия, должна существовать в этом DAT-файле. Подробнее см. [загрузку IP-адресов из файла](https://xtls.github.io/en/config/routing.html#ruleobject) в документации Xray.

Если нужны исходные категории большего числа стран и территорий, можно скачать `geoip-full.dat`, переименовать его в `geoip.dat` и заменить существующий файл. Также замените `geoip-lite.dat` на `geoip-full.dat` в приведённом выше адресе обновления.
